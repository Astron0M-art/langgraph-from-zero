# 生产成长门禁

本项目把“可生产”定义为逐项可验证的工程属性，而不是框架名称或宣传标签。

| 维度 | 早期版本 | 成长版本 | `v1.0.0` 门禁 |
|---|---|---|---|
| 正确性 | 示例与单元测试 | 性质测试、并发和迁移测试 | 固定验收集与回归基线 |
| 持久性 | 内存状态 | checkpoint、schema version | 崩溃恢复、迁移和回滚证据 |
| 副作用 | 无或纯函数 | retry、幂等键、审批 | 重放不重复、审计可追踪 |
| 可观测 | Step 输出 | 结构化事件和 trace | 关键路径指标、错误分类和 replay |
| 安全 | 无真实网络 | adapter 边界和最小权限 | 威胁模型、输入限制、秘密扫描 |
| 评测 | 确定性断言 | trajectory 与 citation eval | 版本化数据、阈值和原始结果 |
| 运维 | 本地运行 | CI、构建、Release | 安装、升级、降级和故障演练 |

## 声明规则

- `v1.0.0` 以前统一标为 pre-alpha/alpha 教学软件。
- 单个演示通过不等于生产就绪。
- 真实模型结果必须记录模型、日期、参数、数据版本、费用和已知不可复现因素。
- fixture 指标只能证明 fixture 范围内的行为，不外推为真实世界成功率。
