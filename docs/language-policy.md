# 语言策略

简体中文是课程讲义和设计结论的事实源。英文入口帮助国际读者理解项目、运行代码和参与贡献。

| 内容 | 语言约定 |
|---|---|
| README 与课程讲义 | 中文为主 |
| 英文项目入口 | 英文，与中文 README 的发布级事实同步 |
| 标识符、公共 API、协议字段 | 英文 |
| Commit message | 英文 Conventional Commits |
| Issue、Discussion、PR | 中文或英文 |
| Release Notes | 中文为主，附英文摘要 |

每次发布时，两份 README 必须同步当前版本、运行命令、能力边界、安全提示、路线、作者和许可证。
完整课程无需机械逐字翻译；英文内容不能反向修改中文讲义已经用源码和测试建立的结论。
