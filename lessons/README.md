# 课程目录

按顺序学习。课程只有一套连续生长的运行时；每个目录冻结“截至该版本”的累计实现，并且不依赖未来
课程代码即可运行。修正已发布快照必须记录在 Changelog 并通过补丁版本发布，不能静默改写历史结论。

| 课程 | 版本 | 当版新增 | 累计包含 |
|---|---|---|---|
| [01 最小状态图](01-minimal-state-graph/README.md) | `v0.1.0` | 确定性节点、静态边、步数预算 | v0.1 |
| [02 条件路由与循环](02-conditional-routing/README.md) | `v0.2.0` | 状态驱动路由与显式终止 | v0.1 + v0.2 |
| [03 State 与 Reducer](03-typed-state-reducers/README.md) | `v0.3.x` | 更新契约、累积与冲突 | v0.1 + v0.2 + v0.3 |
| 04 图编译与静态分析 | `v0.4.0` | 可达性、死端与保留节点检查 | v0.1 至 v0.4，计划中 |

`v0.3.x` 表示工作树已记录 `v0.3.0` 发布后的累计兼容修正；原 tag 保持不可变，修正只有通过补丁
版本流程后才成为新发布物。
